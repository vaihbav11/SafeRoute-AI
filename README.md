# 🚦 SafeRoute AI
### Road Safety Risk Analysis & Intervention Prioritization

SafeRoute AI is a machine learning and data analytics project that analyzes historical road accident data to identify trends, investigate risk patterns, and support evidence-based road safety planning.

## 🎯 Objectives
- Analyze road accidents, injuries, and fatalities.
- Identify patterns in historical accident data.
- Apply and evaluate suitable machine learning models.
- Visualize accident trends and geographic distributions where data permits.
- Support the prioritization of potential road safety interventions.

## 🛠️ Tech Stack
- **Language:** Python
- **Data Analysis:** Pandas, NumPy
- **Machine Learning:** Scikit-learn
- **Visualization:** Matplotlib, Seaborn, Folium
- **Dashboard:** Streamlit

## 📊 Data Sources
- [Road Accidents in India — data.gov.in](https://www.data.gov.in/catalog/road-accidents-india-2019)
- [Persons Injured in Road Accidents — data.gov.in](https://www.data.gov.in/catalog/persons-injured-road-accidents)

Data availability and geographic coverage must be verified before performing location-level risk analysis.

## ⚙️ Installation

```bash
git clone https://github.com/YOUR-USERNAME/SafeRoute-AI.git
cd SafeRoute-AI

```

